# Features

## Purpose

The `features` directory contains all business and AI functionality of the
Enterprise AI Support Platform.

Each feature is completely self-contained and owns its own pages,
components, API calls, hooks, schemas, types, services, and utilities.

## Folder Structure

```text
feature/
├── api/
├── components/
├── hooks/
├── pages/
├── schemas/
├── services/
├── types/
├── utils/
└── index.ts
```
