# Enterprise AI Support Platform Frontend

## Overview

The Enterprise AI Support Platform Frontend is a modern React application that
provides the user interface for the Enterprise AI Support Platform.

It consumes the FastAPI backend and provides a complete enterprise customer
support experience powered by AI.

---

## Technology Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Axios
- TanStack Query
- Zustand
- React Hook Form
- Zod
- Lucide React
- Recharts
- ESLint
- Prettier
- Vitest
